# Forge

**Business model optimization. Email-gated HTML intake, adaptive mental-model analysis with live market research, terminal-noir intelligence report.**

Forge is a Claude Code plugin that takes a business owner through a structured questionnaire, runs an adaptive chain of mental-model lenses against the collected context with live web-sourced market research, and produces a brand-consistent HTML intelligence report covering current state, optimization analysis, proposed redesign, and a three-move implementation plan.

---

## Install

```
/plugin install <path-to-this-repo>
```

The plugin auto-discovers two skills (`intake`, `optimize`) and one hook (`auto-detect-bcd`).

## Use

### 1. Generate an intake form

```
/intake
```

Emits a self-contained HTML questionnaire artifact. Distribute it to workshop applicants (email it, host it, or hand it over). The form is email-gated, multipage, auto-saves between pages, and outputs a Business Context Document (BCD) as a Markdown file when the applicant submits.

### 2. Run optimization on a BCD

```
/optimize <path-to-bcd.md>
```

Or drop the BCD file into `~/forge-intake/` and the auto-detect hook fires `/optimize` for you.

The optimize skill runs four phases:
1. **Web supplement + market research** — scrapes the operator's website (if provided), then WebSearch + WebFetch for TAM, macro signals, competitive density, and industry death-zone bands
2. **Adaptive chain** — mental-model selection with subtractive bias and causal-chain anchors (38-model catalog, 5 causal anchors)
3. **Mermaid diagram synthesis** — six diagrams: AS-IS flowchart, PROPOSED flowchart, Revenue Diff Sankey, Implementation Gantt, Pre-Mortem Quadrant, Revenue Trajectory Chart
4. **Report render** — terminal-noir 8-section HTML intelligence report with sticky theme-toggle header, light/dark toggle, print stylesheet, anchor-link navigation, an effectiveness layer (reading progress bar, scroll-triggered section fade-in, animated number count-up, hover-expand Appendix glossary), and a graceful offline fallback for Mermaid loading

**Report sections:** Executive Summary, Market Intelligence Brief, Where The Business Is Today (AS-IS), Optimization Analysis, The Proposed Model (with PROPOSED diagram + Revenue Sankey), The Implementation Plan (with Gantt), Amplified Moves (compounding additions with three-year revenue projections and trajectory chart), Pressure Test (Steelman/Strawman/Pre-Mortem/Second-Order/What-Survives with Pre-Mortem Quadrant), plus a collapsible Appendix.

### 3. Deliver the report

The optimize skill writes the report HTML to your working directory. Open in browser, share, or print.

## Architecture

```
forge/
├── .claude-plugin/plugin.json
├── skills/intake/       — generates questionnaire HTML
├── skills/optimize/     — runs the analysis pipeline
├── hooks/               — SessionStart auto-detect for new BCDs
├── examples/            — sample rendered report
└── references/
    ├── DESIGN.md            — terminal-noir / terminal-blanc brand spec
    ├── catalog.md           — 38 mental models with kernels + scoring
    ├── visual-primitives.md — Mermaid templates for business-model diagrams
    └── report-structure.md  — gold-standard MBB-derived report structure
```
